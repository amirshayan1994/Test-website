پیاده‌سازی رابط فارسی فقط گذاشتن `dir="rtl"` روی تگ html نیست. اگر بقیه استایل‌ها با فرض چپ‌به‌راست نوشته شده باشند، نتیجه به‌هم‌ریخته می‌شود.

## از ویژگی‌های منطقی استفاده کن

بزرگ‌ترین تغییری که می‌توانی بدهی، کنار گذاشتن `left` و `right` است. CSS مدرن معادل‌های جهت‌آگاه دارد که خودشان با جهت صفحه هماهنگ می‌شوند:

```css
/* به‌جای این */
margin-left: 1rem;
padding-right: 2rem;
border-left: 2px solid;

/* این را بنویس */
margin-inline-start: 1rem;
padding-inline-end: 2rem;
border-inline-start: 2px solid;
```

با این کار یک بار استایل می‌نویسی و در هر دو جهت درست کار می‌کند.

## اعداد و متن انگلیسی

متن فارسی راست‌به‌چپ است، اما کد، URL و اعداد لاتین همچنان چپ‌به‌راست‌اند. برای بلوک‌های کد حتماً جهت را صریح برگردان:

```css
pre, code {
  direction: ltr;
  text-align: left;
}
```

برای تاریخ‌ها هم `Intl.DateTimeFormat` با locale فارسی بهترین گزینه است، چون هم تقویم و هم اعداد را درست نمایش می‌دهد.

## آیکون‌های جهت‌دار

فلش‌ها و آیکون‌های «بعدی / قبلی» معنای جهتی دارند. در چیدمان راست‌به‌چپ، فلش «بعدی» باید به چپ اشاره کند نه راست. این را دستی بررسی کن، چون هیچ ابزاری خودکار درستش نمی‌کند.

## فونت مناسب

فونت انتخابی باید هم فارسی و هم لاتین را خوب پوشش دهد. وزیرمتن گزینه مطمئنی است؛ ارتفاع خط را هم کمی بالاتر از حالت لاتین بگیر — حدود ۱.۸ تا ۲.۱ برای متن بدنه خوانایی را محسوس بهتر می‌کند.

## تست واقعی

بعد از هر تغییر، صفحه را با محتوای واقعی فارسی ببین، نه متن آزمایشی لاتین. خیلی از مشکلات فقط با محتوای واقعی خودشان را نشان می‌دهند.
